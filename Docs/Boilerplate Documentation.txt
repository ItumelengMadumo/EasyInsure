**# Boilerplate Documentation**

## **1. Overview**
This document outlines the structure of the **FastAPI + Angular Boilerplate** used to build the **Insurance Claims Processing Platform**. The system is modular, with components separated by functionality.

## **2. Technology Stack**
- **Backend**: FastAPI (Python), PostgreSQL, Celery, Redis
- **Frontend**: Angular, TypeScript
- **Authentication**: JWT-based authentication
- **Storage**: Cloud storage (S3) for media files
- **Task Processing**: Celery + Redis for notifications & report generation

---

## **4. Key Features**

### **A. Authentication & Authorization**
- Uses **JWT tokens** for authentication.
- First registered user becomes the **superuser (Owner)**.
- Superuser creates **roles** and assigns permissions.
- Role-based access control (RBAC) ensures **only authorized users** can perform actions.

### **B. Claims Management**
- **Clients** can submit claims.
- **Claims officers** review claims, approve/reject them, and add reasoning.
- Changes trigger **notifications** to the client.

### **C. Report Generation**
- Reports summarize claim decisions and are stored in **PostgreSQL**.
- Reports can be **exported as PDFs**.

### **D. Media Uploads**
- Clients can upload **images, videos, and documents** as proof.
- Media is stored in **cloud storage (S3)**.

### **E. Background Tasks & Notifications**
- **Celery workers** handle notifications asynchronously.
- **Redis** is used as a message broker.
- Clients are notified of any claim updates.

## **5. API Endpoints**
### **A. Authentication API**
- `POST /auth/register` – Register a new user
- `POST /auth/login` – Authenticate user & return JWT
- `GET /auth/me` – Get current user details

### **B. Claims API**
- `POST /claims/` – Submit a new claim
- `GET /claims/{id}/` – Get claim details
- `PUT /claims/{id}/` – Update claim (only officers)
- `DELETE /claims/{id}/` – Delete claim (only officers)

### **C. Reports API**
- `GET /reports/{id}/` – Get claim report
- `POST /reports/{claim_id}/generate` – Generate report

## **6. Deployment & Setup**

### **A. Backend Setup**
```bash
cd backend
python -m venv env
source env/bin/activate  # On Windows, use `env\Scripts\activate`
pip install -r requirements.txt
uvicorn main:app --reload
```

### **B. Frontend Setup**
```bash
cd frontend
npm install
ng serve
```

### **C. Running Celery Workers**
```bash
celery -A app.workers.tasks worker --loglevel=info
```
